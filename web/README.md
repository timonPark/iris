# web

Iris의 사용자 웹입니다. 사용자가 질문을 입력하고 Hermes의 답변을 스트리밍으로 보는 채팅 화면입니다.

## 기술 스택

- Vite, React
- 디자인 시스템: Primer (`primer/react`, `primer/primitives`), 라이트와 다크 지원

## 화면

- 로그인, 임시 비밀번호 로그인 직후의 비밀번호 변경, 설정의 비밀번호 변경
- 채팅: 질문 입력(텍스트만), 답변 스트리밍 표시, 중지 버튼, 중단된 답변 표시
- 세션 목록: 스크롤하면 이어서 불러오기, 세션 삭제
- 새로고침하면 새 세션으로 시작하고, 이전 세션은 열어서 볼 수 있습니다.
- "서버 오류", "차단됨" 안내

음성 입력은 모바일 앱에만 있고, 관리자 기능은 `admin/`에 있습니다.
