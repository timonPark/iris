# mobile

Iris의 모바일 앱입니다. iOS와 Android에서 질문을 입력하거나 음성으로 말해서 Hermes의 답변을 스트리밍으로 봅니다.

## 기술 스택

- Flutter (iOS, Android)
- 디자인: Primer 토큰을 Dart 파일로 생성해 사용 (라이트와 다크). Primer는 React용이라 Flutter용 출력이 없어 스크립트로 만듭니다(이슈 #6).

## 화면

- 로그인, 임시 비밀번호 로그인 직후의 비밀번호 변경, 설정의 비밀번호 변경
- 채팅: 텍스트 입력, 답변 스트리밍 표시, 중지 버튼, 중단된 답변 표시
- 세션 목록: 스크롤하면 이어서 불러오기, 세션 삭제. 앱을 종료했다가 다시 열면 새 세션으로 시작합니다.
- 음성 입력: 탭하면 녹음 시작, 다시 탭하면 종료, 최대 2분. 보정된 텍스트가 질문으로 표시되고 바로 답변이 이어집니다.
- "서버 오류", "차단됨" 안내
