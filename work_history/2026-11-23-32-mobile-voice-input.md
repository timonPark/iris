### 사용자와 정한 것 (2026-11-23)
- 마이크 권한이 없을 때: 입력칸 위에 "음성 입력을 쓰려면 마이크 권한이 필요합니다." 안내와 [설정 열기](기기 설정의 이 앱 화면) 버튼. 텍스트 입력은 그대로 쓸 수 있다.

### 이번에 정한 것 (Claude가 정함)
- 녹음: `record`(AAC, m4a, 모노)로 임시 폴더에 쓰고, 올린 뒤 앱이 지운다(서버도 변환 뒤 지운다). 권한은 `permission_handler`, 임시 폴더는 `path_provider`.
- 녹음기를 인터페이스(`VoiceRecorder`)로 두어 테스트는 가짜로 바꾼다.
- 2분 자동 종료 안내는 샘플처럼 처리 중 질문 위의 파란 상자. 인식 실패는 질문 말풍선 없이 규격 문구만(샘플의 인식 실패 화면).
- 빈 화면 안내를 샘플 문구("입력하거나 녹음 버튼을 눌러 말해 보세요. …")로 바꿈(#25에서 녹음 버튼이 생기면 바꾸기로 한 것).
- Android compileSdk를 37로 올림(`permission_handler_android` 요구).
- 2분 자동 종료는 1초 남기고(1:59) 끝낸다. 백엔드가 2분을 0.1초만 넘어도 거절하고, 시작·멈춤 지연만큼 실제 녹음이 길어질 수 있어서다(agy 리뷰).
- 새 문구: 녹음기 실패 시 "녹음하지 못했습니다. 다시 시도해 주세요."(codex 리뷰).
- 2분 자동 종료 안내는 처리 중일 때만 보인다(샘플의 처리 중 화면 위 안내, agy 리뷰).
