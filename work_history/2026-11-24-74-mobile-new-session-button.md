## 작업 내용

이전 세션을 연 뒤 빈 새 세션으로 돌아갈 방법이 앱을 완전히 종료했다가 다시 여는 것뿐이다. 세션 서랍에 [새 세션] 버튼을 만든다.

범위
- 포함: 세션 서랍에 [새 세션] 버튼. 누르면 서랍을 닫고 빈 새 세션 화면이 되며 다음 질문부터 새 세션이 된다. 녹음 중이면 다른 세션을 열 때처럼 녹음을 버린다.
- 제외: 백엔드 API 변경(`sessionId` 없이 질문하면 이미 새 세션이 만들어진다)

완료 조건
- [ ] 이전 세션을 연 뒤 [새 세션]을 누르면 빈 화면이 되고, 다음 질문이 새 세션으로 저장되어 목록 맨 위에 생긴다.
- [ ] 이전 세션에는 그 질문이 들어가지 않는다.

결정 필요: 에픽 #72의 결정 필요를 따른다(`ssot/GLOSSARY.md` "세션").
- 이미 빈 새 세션이면 아무 일도 없다.
- 답변을 받는 중이면 다른 세션을 열 때처럼 받던 답변은 뒤에서 끝까지 받아 저장한다.
- 버튼 모양: 웹(#73)과 같게, 서랍의 "세션" 제목 위에 서랍 폭만큼 넓은 [+ 새 세션](2026-11-24 사용자 결정).
