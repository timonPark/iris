# admin

Iris의 관리자 웹입니다. 관리자가 사용자 계정을 관리하는 별도 웹 화면입니다.

## 기술 스택

- 디자인 시스템: Primer (`primer/react`, `primer/primitives`), 라이트와 다크 지원
- Vite + React + TypeScript. 사용자 웹과 같은 스택입니다(#12에서 확정).

## 하는 일

- 사용자 계정 목록(페이징), 등록, 차단과 해제, 비밀번호 초기화
- 등록과 비밀번호 초기화 때 시스템이 만든 임시 비밀번호를 한 번만 보여줍니다.

관리자 계정은 설정(`.env`)으로만 만들고 관리자 웹에서 다루지 않습니다. 대화 열람은 없습니다.
