# ssot

Iris의 용어와 개념을 정리한 단일 기준(Single Source of Truth) 폴더입니다.
backend, web, admin, mobile은 이 폴더의 내용을 기준으로 작업합니다.

- 용어와 개념이 이 폴더와 코드가 다르면 이 폴더가 맞습니다. 코드를 고치거나, 이 폴더를 먼저 고치고 반영합니다.
- 정의가 없거나 모호하면 임의로 정하지 말고 이 폴더에 먼저 정리합니다.
- 용어집은 `GLOSSARY.md` 하나만 둡니다. 프로젝트마다 다르게 쓰는 용어는 없습니다. 한 프로젝트에만 필요한 용어도 여기에 추가해서 4개 프로젝트가 같이 씁니다.
