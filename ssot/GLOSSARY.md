# Iris

웹과 모바일 앱의 채팅 화면에서 입력한 질문을 백엔드가 이 PC의 Hermes에 전달하고, 답변을 스트리밍으로 돌려주는 서비스. 이 문서는 4개 프로젝트(backend, web, admin, mobile)가 함께 쓰는 단일 용어 기준이다.

## Language

### 구성 요소

**백엔드**:
모든 클라이언트의 유일한 입구가 되는 서버. `backend/`.
_Avoid_: 서버, API 서버 (Hermes API 서버와 혼동)

**사용자 웹**:
사용자가 채팅에 쓰는 웹 화면. `web/`.
_Avoid_: 웹 (단독 사용), 프론트

**관리자 웹**:
관리자가 사용자 계정을 등록, 차단, 비밀번호 초기화하는 별도 웹 화면. 관리자 계정은 다루지 않는다. 사용자 계정으로는 로그인하지 않는다. 로그인 응답의 역할이 사용자면 토큰을 저장하지 않고 "관리자 계정만 로그인할 수 있습니다."라고 안내한다(관리자 API는 백엔드가 막는다. #4에서 정함). `admin/`.
_Avoid_: 어드민, 관리자 페이지

**모바일 앱**:
iOS와 Android에서 쓰는 Flutter 앱. `mobile/`.
_Avoid_: 앱 (단독 사용)

**클라이언트**:
백엔드를 호출하는 사용자 웹, 관리자 웹, 모바일 앱 전부.

**사용자 앱**:
클라이언트 중 사용자가 쓰는 사용자 웹과 모바일 앱. 관리자 계정으로는 로그인하지 않는다. 로그인 응답의 역할이 관리자면 토큰을 저장하지 않고 "관리자 계정은 관리자 웹을 이용해 주세요."라고 안내한다(백엔드는 막지 않으므로 사용자 앱이 막는다. #18에서 정함).
_Avoid_: 사용자 화면

### 외부 시스템

**Hermes**:
이 PC에서 실행되는 에이전트. 질문에 답하고, 옵시디언에 기억을 저장하고 조회한다. 그 동작은 Iris의 구현 대상이 아니다.
_Avoid_: 에이전트, AI

**Hermes API 서버**:
백엔드가 Hermes를 호출하는 HTTP 접점. 키는 백엔드만 보관한다.
_Avoid_: Hermes 서버

### 계정과 역할

**계정**:
로그인할 수 있는 주체. 아이디, 비밀번호 해시, 역할, 상태를 가진다.
_Avoid_: 회원, 유저

**역할**:
계정이 가진 권한 구분. 관리자 또는 사용자 중 하나.
_Avoid_: 권한 등급

**사용자**:
역할이 사용자인 계정. 채팅을 쓴다. 관리자는 포함하지 않는다.
_Avoid_: 일반 사용자, 유저

**관리자**:
역할이 관리자인 계정. 관리자 웹에서 계정을 관리한다. 첫 관리자 계정은 설정으로 주입한다.
_Avoid_: 어드민

**상태**:
계정의 활성 여부. 활성 또는 차단 중 하나.

**차단**:
관리자가 계정을 로그인할 수 없게 만드는 상태. 해제할 수 있고, 차단해도 세션 기록은 남는다. 계정 삭제는 없다.
_Avoid_: 정지, 비활성화, 삭제

**비밀번호 초기화**:
관리자가 계정에 임시 비밀번호를 발급하는 일. 관리자가 그 값을 사용자에게 전달한다.
_Avoid_: 비밀번호 리셋

**임시 비밀번호**:
비밀번호 초기화로 발급된 비밀번호. 사용자는 이것으로 로그인한 뒤 새 비밀번호로 바꾼다.

### 대화

**세션**:
사이드바 목록에 나열되는 대화 하나. 웹에서 새로고침하거나 앱을 종료했다가 다시 열면 새 세션이 생성된다. 이전 세션은 지난 대화의 흐름을 보는 용도이고, 대화 맥락은 현재 세션에서만 이어지면 된다. 사용자는 자기 세션을 삭제할 수 있고, 삭제한 세션은 사용자에게 보이지 않는다. 영구 삭제는 하지 않는다.
_Avoid_: 채팅방, 대화방

**스레드**:
세션 안에서 질문과 답변이 순서대로 이어지는 흐름. 스레드만 따로 삭제할 수 없고, 삭제는 세션 단위로만 한다.
_Avoid_: 타래

**질문**:
사용자가 보낸 텍스트 메시지. 직접 입력했든 음성 입력으로 변환했든 구분하지 않는다.
_Avoid_: 프롬프트

**음성 입력**:
녹음을 텍스트로 바꿔 질문으로 만드는 모바일 앱 전용 경로. 사용자 웹에는 없고, 원본 음성은 저장하지 않는다. 텍스트 입력도 모바일 앱에서 함께 쓸 수 있다.
녹음 버튼을 탭하면 녹음을 시작하고, 다시 탭하면(녹음 중에는 그 자리가 보내기 버튼이 된다) 끝내고 바로 보낸다. 최대 2분이고, 2분이 되면 자동으로 끝내고 보낸다. 녹음 중에는 지난 시간과 최대 길이를 함께 보여주고(예: `0:42 / 2:00`), 취소 버튼으로 보내지 않고 버릴 수 있다. 보정된 텍스트는 질문으로 표시되고 수정 단계 없이 바로 답변이 이어진다(#5에서 정함). 마이크 권한이 없으면 "음성 입력을 쓰려면 마이크 권한이 필요합니다." 안내와 기기 설정을 여는 버튼을 보여주고, 텍스트 입력은 그대로 쓸 수 있다. 녹음 중에 모바일 앱이 백그라운드로 가면 녹음을 보내지 않고 버리고, 돌아오면 "다른 화면으로 나가서 녹음을 취소했습니다."라고 안내한다(#32에서 정함).
_Avoid_: 음성 질문

**답변**:
질문에 대해 Hermes가 스트리밍으로 돌려주는 텍스트. 질문과 한 쌍으로 세션에 저장된다. 받는 도중 연결이 끊겨도 서버는 답변을 끝까지 받아 저장한다(`adr/0003`). 모바일 앱은 끊기면 받은 부분까지 두고 "연결이 끊겼습니다. 답변은 서버에서 계속 저장됩니다."라고 안내하고, 다시 앞으로 오면 그 세션을 다시 불러와 저장된 답변을 보여준다(#25에서 정함).
_Avoid_: 응답

**대화 기록**:
Iris DB에 저장된 모든 세션의 질문과 답변. 사용자는 자기 것만 볼 수 있고, 관리자 웹에서는 볼 수 없다.
_Avoid_: 채팅 로그
